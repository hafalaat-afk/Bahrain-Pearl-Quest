# 🇧🇭 Bahrain Pearl Quest | رحلة لآلئ البحرين

An illustrated bilingual oyster-diving quiz inspired by Bahrain's traditional pearl-diving heritage, featuring its history, heritage, landmarks and achievements.

**Modes:**
- **Individual play:** one device, 16 interactive oyster challenges, automatic scoring, a final result and replay. No backend needed.
- **Live group play:** create a room as host, display a scannable QR code, guests join from their own phone and enter usernames, press **Start** once to begin the synchronized 16-question game, and display individual results and a leaderboard at the finish.

**Estimated gameplay:** ~4–5 minutes with 14-second questions and 3-second reveals.

**Start:** Open `index.html` locally to try solo mode. For live multiplayer, see [SETUP_LIVE.md](SETUP_LIVE.md). GitHub Pages hosts the website, while Firebase enables real-time cross-device play. `firebase-config.js` must be completed by the organizer. Guests do not need Firebase accounts.

**Included files:** `index.html`, `multiplayer.js`, `multiplayer.css`, `firebase-config.js`, `database.rules.json`, `SETUP_LIVE.md`, `.nojekyll`, `vendor/qr.js` and its license.
